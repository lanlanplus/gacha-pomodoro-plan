# 四项装饰修正

本轮仅修改 styles.css；changes.diff 是相对于上一轮交付的增量，不包含上一轮尚未提交的更改。

- 两个色块取消旋转。绿色块位于进度条下方偏左；三色块在 Web 标题行右侧，移动端位于清空重装下方右侧空白区，避免遮字。
- 七个贴纸 opacity: 0.55，filter: saturate(0.75)。色块维持原透明度。
- 色带移除 mask-image；实际计算样式 mask-image: none、filter: none。
- 阴影伪元素生效，无覆盖问题。旧阴影大部分被机底遮住，且透明度低、模糊半径大。新阴影延伸到机底外，采用更深的双层渐变及 3px 阴影模糊；色带本身没有模糊。
